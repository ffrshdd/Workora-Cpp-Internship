# Basic Calculator in C++

A menu-driven console calculator developed in C++ as part of the Workora C++ Programming Internship.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Division-by-zero handling
- Invalid input handling
- Continuous execution through a menu loop
- Exit option

## Technologies Used

- C++
- iostream
- switch-case
- do-while loop
- Input validation

## How to Run

### Compile

```bash
g++ calculator.cpp -o calculator
